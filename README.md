# 📊 Business Analytics Dashboard

A simple and interactive dashboard to understand business performance through sales, revenue, expenses, and profit analysis.

## 👨‍💻 About the Project

This project presents business performance data through KPI cards, charts, and a product performance table.

It helps users understand key business metrics and explore sales performance across different regions.

## ✨ Features

- Total Revenue and Expenses
- Net Profit and Profit Margin
- Total Orders and Average Order Value
- Monthly Revenue vs Expenses chart
- Regional Revenue chart
- Product Performance table
- Interactive time-period filter
- Responsive design for mobile and desktop

## 🛠️ Tools Used

- HTML
- CSS
- JavaScript
- Chart.js
- GitHub Pages

## 📈 Key Business Metrics

- Revenue
- Expenses
- Net Profit
- Profit Margin
- Average Order Value
- Product Performance
